# Bounded agent-effort comparison

This is a synthetic engineering workflow check, not a financial experiment. The fixed packet and separate rubric were written before any responses. Four independent fresh-context runs are requested: two Astra Medium and two Astra High, all with identical input and output contracts. Workers are instructed to read the packet only and receive neither the rubric nor another worker's response. The filesystem is shared; this is instruction-based blinding, not access isolation.

The packet covers return accounting, point-in-time availability and exposed-sample reuse, a small concurrent ledger implementation, and qualified source-backed configuration advice. Functional checks assess the proposed code on temporary invented data. An independent reviewer assesses material omissions against the withheld rubric and functional evidence. No participant executes a trading strategy or accesses account data.

Elapsed times are worker-reported wall time when available, not controlled model latency. Shared account usage cannot be reliably allocated to an individual run, so token/cost savings will not be asserted. Two repetitions per effort establish only a small smoke comparison; no optimality, universal superiority or strategy-design equivalence follows. The provisional policy may use High for coordination and Medium for bounded work only if the observed results support that scope, with independent review retained.
