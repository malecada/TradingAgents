## Engineering acceptance

1. Trading PnL uses simple returns at each caller. NAV includes initial capital, every clock period and signed funding. Holdings drift with price/NAV between actual rebalances. At a rebalance, desired notionals are sized from pretrade NAV; fees are charged once against actual notional changes. The resulting postfee exposure is explicit. Missing held-instrument prices cause an explicit failure; an absent signal does not silently erase an occupied period. Hourly NAV returns compound to daily NAV returns. Historical data with unresolvable settlement remains unvalidated.
2. A missing or unavailable forecast is distinct from a numeric forecast. ENet and probability adapters preserve failure status. The runner substitutes the same already-declared baseline on missing/nonfinite predictions or nonpositive variance forecasts, retains raw forecast and fallback reason, and reports model coverage on a common clock. No comparison may silently discard invalid model forecasts. Only available baseline/target origins are scoreable, with exclusions counted. Existing historical results are preserved.
3. DEX normalization uses strictly prior completed observations available before the decision (same-timestamp rows cannot inform each other); missing features remain missing. Intraday ETH conversion uses the last fully closed five-minute quote at or before the event, with an explicit timestamp/cadence and no same-day future close. Historical versioned data use actual retrieval/publication-version availability; synthetic old availability is not silently treated as exact PIT. Same-key conflicting data cannot overwrite existing vintages.
4. Live order state separates intent, submission, unknown status, fills and reconciled completion. A failed or unknown batch remains incomplete and retryable through exchange-position/order reconciliation. Unknown order POSTs cannot be blindly resubmitted. Emergency halt prevents exposure increases while residual closure is reported accurately. Dry runs never consume live completion. Stale signal/mark rows and partial missing marks suspend affected execution without converting missing prices into desired exits. Whole batch risk includes held exposure; hedge mode is rejected before any flatten attempt.
5. Paper and research share calendar universe and signal construction with the trade date explicit. Forward measurement is versioned; old journals are not mixed with corrected net/funded/fee/scale definitions. Code checks data freshness and reports incomplete measurement. The VPS is not deployed or mutated by this task.
6. Evidence identity includes experiment, cell, model, config and window; provenance includes code/gate/data hashes. New research logging requires committed registration and clean executable source. An append-only corrections register resolves invalidated/superseded results without editing originals. Formula fixes retain legacy evidence; any change to inferential policy is prospective and disclosed.
7. The manuscript withdraws invalidated strategy, venue and capacity claims in both languages and every included table/figure; the findings are bounded to tested configurations. It reports software correctness separately from strategy validation. Sources and compiled PDF must agree. No unsupported profitability is substituted.

## Resolution of design alternatives

Existing raw data and results remain immutable. Unsupported historical availability cannot be recreated; it is quarantined or qualified. Explicit baseline fallback was selected over confident numeric zero or silent row deletion. Fixed contract holdings between declared rebalances were selected over free constant-mix maintenance. Strictly prior normalization was selected over retrospective cohort scaling. A unified correction branch contains both previously separate research packages; original branches stay available for provenance. These choices are versioned corrections, not new alpha claims.
