## Confirmed findings

1. **P1 — Frozen residual execution becomes unretryable after the original paper quote expires.** In `scripts/predlab_s1_live.py:291–296`, the 600-second age check on the paper row precedes lookup of an already frozen batch at `:299–315`. A batch with AAA filled and BBB rejected can retry immediately, but an 11-minute retry returns `WAIT: stale or future champion marks`, even with fresh exchange quotes and the correct signal/trade date. The original paper row cannot refresh itself: `scripts/predlab_s1_paper.py:302–303` skips an existing as-of row, and `:356–375` skips the daily pre-fetch path. The remaining BBB target is therefore stranded on a later scheduled wake. An existing frozen target needs reconciliation under fresh current exchange quotes and unchanged signal-day/risk checks without requiring the obsolete quote used to establish its original instruction. A new target should retain the original freshness requirement.

2. **P2 — A canceled order with an actual partial fill disappears from fill and fee reporting.** `scripts/predlab_s1_live.py:141–155` writes a fill record only for `status == 'FILLED'`. A `CANCELED` response with `executedQty=5` is omitted. A separate completed order with known commission then produces `fee_coverage='complete'` and total fees of 0.01 USDT for only one of two executed orders. Position reconciliation alone cannot repair that reporting denominator. Record positive executed quantity regardless of the final order status, and deduplicate cumulative order/trade observations so repeated partial/final status snapshots cannot count fills or fees twice. Fee completeness must also cover the observed executed quantity.

The synthetic probe uses temporary journals and a fake exchange whose fills change its position state. Its first batch left actual positions `AAAUSDT=37` against a frozen target additionally containing `BBBUSDT=-7`; after 11 minutes the remaining position was still absent. The second probe reported one fill and complete fees despite the canceled order's positive execution. The full pre-fix output is retained in `verification/independent-accounting-execution-probes.json`; the executable probe is `verification/independent-accounting-execution-probes.py`.

The root added regression tests for both findings. A focused run captured those two failures with **114 passing cases and 2 failures in 2.89 seconds**. The exact failing tests were `test_frozen_residual_retries_after_paper_quote_expires` and `test_partial_cancel_is_counted_and_cumulative_snapshots_not_double_counted`. This is retained red evidence, not a green completion claim.

The remaining OI behavior is at `tradingagents/predlab/features.py:74`: pandas `resample(...).last()` independently chooses the last nonnull value of each column. `_t2_features` in `scripts/predlab_run_battery.py:363–367` joins those features without per-field source timestamps or coverage counts. A probe with a complete two-hour 5-minute timestamp grid but only one finite value per ratio in the first hour yielded all three next-hour features from observations at 00:00, 00:30 and 00:55. Thus complete timestamps do not establish complete fields or a simultaneous end-of-period vector. The data audit separately reported 4,342/3,881 missing BTC/ETH 5-minute timestamps, plus additional null fields; no historical source check was repeated here.

This OI probe does **not** establish look-ahead or a broken same-row identity. Every selected value precedes the completed bucket boundary and all output features shift by one period. The ratios enter as separate covariates; no audited caller requires them to be a simultaneous snapshot. Retain and disclose this as asynchronous last-observation sampling with no minimum field-coverage rule. Per-field counts/source timestamps or a stricter minimum-coverage requirement would make a useful explicit prospective contract, but changing that sampling policy is not an automatic historical repair and would require registration before another model comparison. Task B's explicit unavailable-forecast handling prevents known feature absence from silently becoming confident ENet output; it does not manufacture missing OI information.
