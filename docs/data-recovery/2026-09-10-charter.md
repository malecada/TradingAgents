## Data and implementation acceptance

Rebuilt snapshots must preserve every original row, insert only verified missing observations, document UTC open/close conventions, and disclose source hashes, schema/units, date ranges, duplicates, holes and overlap comparisons. Genuine missing bars remain missing when the provider cannot establish them. Zero-volume padding is not a settlement instruction. Original data and existing strategies are not changed by filling, forward-filling, retrospective removal, ticker renaming or fabricated terminal prices.

Coverage-control repairs receive synthetic regression tests and independent review. Any contract-event accounting extension is designed only after the required evidence exists, with hand-derived long/short, fees, funding and termination tests. No empirical result informs a changed trading rule. The current scope does not rerun NLST4, forecasts, S2/S3, or any already measured result merely to search again.

## Replay boundary

A data change can affect previously measurable cells too, so the affected family must be retained in full. All prior holdout spending remains in force. If recovery is incomplete, report the remaining specific evidence requirement rather than a negative strategy verdict.
