# Q4 and Q6: bounded inherited-source investigation

The separately registered Q4 and Q6 claims address distinct prerequisites under
PHASE.md. No financial recipe, signal, ranking, token selection, archive fetch,
news query, account operation or production change is authorized here. Each has
one finite source allowance and no overall elapsed/CPU-time cutoff. No source
file is imported as executable code; only text and AST are inspected.

Q4 asks whether the existing new-pool/wallet-flow lineage can support a causal
mature-token adoption study. q4-design.json fixes eight code files and eight
metadata targets (four exact JSON candidates in each of two known worktrees).
The draft $10m–$250m cap and90-day age are unadmitted proposals. Full365-day
holding-period coverage, failed-token retention, historical circulating supply,
unlocks, an adoption-to-token-value mechanism and two-way sellability require
actual evidence. Long historical coverage or an old wallet signal alone does
not establish any of them.

nonregular files, files above4MiB, changes during reads, duplicate JSON keys,
nonfinite constants, structures above100000nodes or32levels. Retain pre/post file identities, every byte read and SHA256 even on failure,
distinguishing a stable complete file from a received prefix. No cap+1 sentinel
read is permitted. Publish each target intent before reading. The source path
is not an immutable captured copy; concurrent changes remain unavailable. Existing raw files remain immutable at their original
paths; no raw arrays or numeric observations are published. Sanitize to the
pinned FIELDS allowlist and field-type counts. Other dynamic keys are aggregated
as hash/count, with no token names/addresses/text. Date-shaped dictionary keys
are merely metadata, not proof of availability. Structure is capped at120KiB,
each cell at128KiB; overflow retains unavailable status and the file digest.
Eight files permit32MiB maximum source metadata reads. No retries or search for
substitute files. Missing metadata is source unavailability, not absent alpha.
