## Evidence and ownership

`decode_evidence` binds the separately registered F1 claim/terminal bytes to their
packet hashes and audit provenance. Each embedded original file is Base64 decoded
and checked against either a registered F1 input hash or its terminal output hash.
The bundle is a copy of identifiable original bytes, not a substitute source.
The prior F1 source-context packet is itself pinned by that original claim; its
retained header/price proof is reparsed under the unchanged previously reviewed
context rules. Final actual admission still requires the original F1 structural
closure and complete ownership review, rather than trust in a self-authored audit.

Every declared F1 physical source intent, including unused retries and suppressed
slots, is required by the reconstruction. Attempted request keys extend the full
inherited exclusion set. The prepared route first calls the reviewed terminal
structural/raw audit and requires a complete F1 publication, so an unpaired
uncertain send or failed terminal cannot be transferred under this route.
Reconstruction rejects missing physical intents, changed canonical keys and new
LP calls overlapping prior actual/uncertain keys. The source-summary endpoint
stop blocks preparation. The audit's physical/raw counts now must match the
hash-bound terminal source summary before they enter the successor resource budget.

Successful shared headers are raw-reparsed against exact height and actual clock;
prices require the same canonical hash, fixed oracle and exact ETH/USDC vector.
USDC decimals and bytecode require the same action/address/hash and strict raw
parsing before their values can be reused. A failed common header/price/USDC
witness remains unavailable and is never requested again. The implementation is
conservative: it does not transfer any suppressed common source slot to a new
F3 attempt. It therefore may leave more shared data unavailable than a future
separately reviewed route could justify; it does not silently exercise that route.
Genuinely new LP-only getters remain conditional on available shared headers.
