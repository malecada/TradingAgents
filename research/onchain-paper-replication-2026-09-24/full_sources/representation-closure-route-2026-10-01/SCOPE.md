# Sequential complete graph closure candidate

This component prepares an in-memory metadata closure from the actual current
registered owner, registered denominator adapter and issued dictionary ticket.
A selected policy shared by plan and execution job supplies exact saved graph
admission input names, maximum graph count, encoded record allowance and maximum
sequential numeric allowance. Both declared MCM-read and graph-read numeric
ceilings must fit the latter before graph admission.

The journal must contain exactly one MCM progress and one graph completion for
each required graph, with no representation completion, embedding progress or
unfinished dictionary progress. The full journal prefix is retained and checked.
Every graph is independently admitted through the real saved graph route, which
joins original MCM values, native graph bytes, source/proof/event/policy identity
and bounded CPU tensor conversion. The numeric receipt is discarded before the
next graph; only compact records remain. Metadata snapshots and strict component
inventories/signatures cover both MCM and graph artifacts after individual numeric
receipts have been released. Dictionary/sample leases remain retained.

The schema3 motif binding uses the extended registered workflow identity and
contains every required feature hash plus raw graph lineage for the union of
required graphs and all dictionary training graphs. A training graph absent from
included examples must not disappear from dictionary provenance. Edge lineage
hashing streams C-order chunks and also defines empty edges without the historical
multidimensional-memoryview limitation. Complete date accounting and all recorded
price omissions remain attached; price-based exclusions are not independently
validated. GAT stays trainable in the temporal model, not in the fixed graph input.

This is not durable representation publication, a sealed/historical/mapped owner
route or empirical release. The Receipt is an in-process lease contract, not an
issued capability accepted from arbitrary callers. Consumers must call actual
admission and check its lease. Per-graph signatures detect drift, not atomic
protection against continuous mutation. Parent resident graphs, retained dictionary
and sample arrays, Python/metadata serialization, page cache and model state are
not counted by the sequential numeric ceiling. The record cap applies to encoded
output; it is not a pre-allocation metadata memory bound. Exact physical quotas,
whole-workflow RSS and scalable leases remain separate requirements.

New synthetic evidence uses actual temporary registration, complete examples,
sampler/dictionary fitting and two required native graph artifacts. A third graph
belongs to the dictionary training population but no included example. All27daily
decisions remain included or explicitly excluded. Only kernel guard observations
are mocked; there is no raw financial data, financial model fit or budget use.
The test checks incomplete/duplicate graph denial before graph-array admission,
full lineage, actual sequential tensor release through weak references, no fresh
dictionary admission during reuse and later stored-array drift refusal.
