# Constructor-only same-boundary metadata reuse candidate

Future candidate only; Main, active native21, Git, registrations, STATE and numerical settings are untouched. Two candidate files are supplied: imported_authority_lease.py and imported_mcm_identity.py. No compact_mcm change is needed. No runtime speed or memory improvement was measured.

The scope is exactly the two immediately adjacent `_checkpoint(execution); execution.check()` sequences in Target construction. Those become two `_checkpoint(execution,value=True)` calls. The first result remains unused; the second initializes the same execution metadata/pin as before. Four forced constructor boundaries remain. The other two constructor checkpoints, and Target.check/final/lease/sources/derive_scope/_pins, are unchanged. In particular, Target.check's execution check follows another lease and a manifest read; it is deliberately not removed because that is not the same uninterrupted boundary.

Static effect: two direct full execution checks removed per Target constructor, or14 in eager construction of seven targets. This does not eliminate the previously counted126 eager execution checks and is not a measured timing saving. One full execution check still runs inside each of the four original forced boundaries.

The existing Lease gains an internal optional returned-value path, requiring literal full boundary selection. `_full` returns the actual canonical result of its existing execution.check after the existing source/code and target rechecks. The selected Lease.check captures that return in an invocation-local list, never a persistent result cache. It requires exactly one result and unchanged baseline bytes. After scheduler callbacks, the last clock read and unchanged max_stale threshold check precede the callback-free final rejoin: genuine compact Owner verification, stage integrity, materialized original integrity, source/input/module fingerprints, authority-object pins, baseline equality and canonical execution/current/original metadata equality. The returned object is parsed independently from captured bytes.

No delayed handle, synthetic Owner, token, alternate authority type or long-lived source cache is introduced. The ordinary `_return_value=False` path retains its original scheduler full/fingerprint/live callback selection, final identity check and None result. `_full` now returns bytes, which existing ordinary callers ignore. Without the registered sampled lease, each selected constructor checkpoint calls execution.check once, preserving the original fallback's check count and metadata value. The existing module-level check fallback remains unchanged when no lease exists. All failures inside the Lease method continue to poison both Lease and scheduler and rethrow the original BaseException.

The extra post-scheduler work follows the existing sampled, non-atomic currentness contract; it does not establish atomic external-writer exclusion. No policy intervals, call limits or stale thresholds are raised. Full admission/Git work is reused only for the immediately adjacent constructor result; current Owner, stage, numeric identity and source-fingerprint checks remain at return. Internal live checks inherent in the removed redundant full execution invocation disappear with that invocation; the original Lease boundary's mandatory live and full checks remain. This distinction is explicit rather than claiming identical counts of redundant nested live calls.
