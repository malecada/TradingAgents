# Lazy exact edge-agreement reuse — bounded candidate

Uninstalled source candidate against the current Main ordered-Q implementation. Only the within-call edge weight calculation gains reuse; V/M/Q/state/META/checkpoint schemas, edge traversal, Q multiplication/addition, normalization, beta schedule, operation accounting and ranking remain unchanged. No actual scientific input or label was read. Main, current entries, previous evidence and native jobs were not modified.

## Eligible domain and lifetime

The cache is local to one `_advance_checked` call and discarded on return/error. The complete edge-product domain must have1–4096 positions and the call budget must exceed one sweep. Both graphs must have exact scientific AttributedGraph type; edge_features must be exact contiguous native-float64 ndarrays backed through at most four readonly ndarray links by an actual immutable bytes object. Merely readonly arrays with mutable/owned backing refuse reuse. State arrays must be exact ndarrays.

Agreement identity/code, its math.exp/fsum and builtin float/zip/len dependencies, direct NumPy operations and logsumexp identity/code are pinned. Initial eligibility requires original pins, no tracing/profiling and round-to-nearest. Linux/libc fegetround is accessed through stdlib ctypes; absent support or nonzero rounding mode disables reuse. Original-function/default-rounding checks and exact feature-object pins are rejoined at every outer iteration boundary. No per-hit source or authority checks are added. A failed boundary guard permanently disables/discards this call's cache.

This eligibility is tied to the frozen, exclusively owned scientific runtime already required by the caller. It does not claim immunity to arbitrary concurrent Python mutation, arbitrary transitive SciPy dependency replacement, monitoring/instrumentation callbacks or foreign fenv changes halfway through a primitive. Those violate the frozen/no-intervening-callback assumption; no new universal Python authority framework is introduced. Direct supported monkeypatches and non-default rounding are tested to fall back. Existing source/runtime authority remains unchanged.

## Lazy semantics and allocation

The first traversal calls the exact original `.5*agreement(...)` at its original edge position. Only a successful rounded value is written into the local float64 cache and its validity bit. Missing positions are never evaluated early; no error or unsuccessful weight is cached. On later visits within the same call, the exact saved weight is copied into the original weights vector. The subsequent float64 multiply by the current M and ordered np.add.at updates are unchanged. The original successful-prefix replay remains responsible for agreement errors.

Reuse is only reached in the existing eligible vector branch. All original scalar fallback cases remain literal. Large domains, mutable backing, unsupported graph types/runtime, small vector chunks and calls not revisiting edges retain the original calculation. Checkpoint interruption discards reuse and recomputes misses on the resumed call; no graph/result/checkpoint alias is introduced.

Maximum additional numeric payload is4096*8+4096*1=**36864B**, plus two small ndarray headers and fixed references. The accepted ordered-edge scratch estimate is below160KiB; their sum remains below200KiB with more than56KiB headroom inside the existing262144B combined edge/reuse reservation. No feature-row copies or full-domain table beyond4096 positions are created. This retains the existing reservation scope: dense retained state, validation/normalization allocations and interpreter/library baseline were already excluded from that edge scratch estimate. The cache survives normalization, so Root's whole-process resource review must include those existing simultaneous allocations; this is not a newly measured RSS bound or permission to raise a cap. Allocation failure is not equivalent to a successful baseline run and remains subject to the outer resource envelope.

## Focused proof

TEST01 passes37 bitwise boundary comparisons across whole-call multi-temperature reuse, interrupted budgets7/8/19/103 and73/128, and both directions of real checkpoint save/load/resume. Final assignment/soft-assignment/scalar bits agree. Original error type/message/Q/cursor/safe state agree for agreement overflow at the original later edge. A monkeypatched counting/failing agreement takes the original path and has the same call count/error prefix. Mutable readonly-owned backing, directly patched normalizer and non-nearest rounding refuse reuse. TEST02 adds three cases for signed-zero features, successful underflowed weights and a5184-product large-pair fallback. No old full matrix was rerun; all test receipts/fixtures remain.

Seven small synthetic full-advance samples had medians about0.003132s baseline and0.002073s candidate, approximately**1.51x**. This proves a tiny eligible-case benefit, not observed population frequency, complete real-data throughput, full feature completion or financial validity. Large products have no reuse benefit and the added eligibility guard may have overhead. The actual first-graph56,584,576-pair denominator was not reduced.

Commands used pinned Python with AS256MiB, FSIZE4MiB,60s timeout, nice10 and read-back affinity[0,1] (two logical CPUs, no isolation claim). No external data, network, empirical registration, native job or complete test suite was involved. Exact baseline/candidate/inverse hashes are in MANIFEST.json. Independent review and Root integration remain pending.
