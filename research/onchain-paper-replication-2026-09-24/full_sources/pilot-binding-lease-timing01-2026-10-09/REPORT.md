# Opt-in Binding.lease phase timing candidate

Uninstalled source only. Binding.lease(observer=None) retains the literal original body and original None return behavior without timer/observer calls. Explicit selection requires exact BindingLeaseTiming(binding) and lease(observer=that_observer). No existing caller is changed or automatically selected; no live28 metrics are produced.

Four fixed phases are first_guard, journal (ancestry/parent entries and terminal-marker observations), snapshots (reader selection and exact metadata joins), second_guard. Genuine run._active and directory construction remain before those phases, untimed. Every original check, branch, observation and guard order remains unchanged; AST inverse proves both the legacy body and the measured body after removing only observer contexts equal the original statements. No cadence, authority, currentness or data caching changes.

Observer pins the actual Binding object and the captured time.monotonic_ns callable. There is no external clock parameter; production uses that builtin, while the fixture supplies a synthetic clock only in its extracted test namespace. Per-phase calls/ns/failures are12 bounded nonnegative signed63-bit integers, plus binding_timing_closed. Callback timing samples two clocks per entered phase. A successfully recorded failing original phase increments failure count. A clock/identity/counter error poisons the observer; if an original exception already exists it remains the exact primary object with a timing-error note. Otherwise the timing error propagates and subsequent checks do not run. Timing failure may leave that occurrence unrecorded; retained counters do not certify it completed. The default direct route is unaffected.

Clock sampling, validation and counters add overhead and can introduce a new selected-route failure. These counters measure inclusive nested wall time, not CPU time or causal attribution. They must not be added to an enclosing authority callback total as independent work. Timing does not claim an atomic observation, immutable filesystem, scientific completeness or genuine authorization.
