## Verification and limits

The pinned local Python runs actual repository imports and the original
`_loaded`, `_authenticate_loaded` and snapshot equality predicate. Original
preactivation import statements are replayed without calling scientific code.
Selected future imports and original dynamic kernel/workload imports leave the
prepared snapshot unchanged. Replaced function identity, replaced function code,
and incorrect authenticated source hash still refuse. Original source files are
never modified by these mutation checks. No fake Lease or authority is created.

The watchdog enforces a 120-second wall bound and kills at sampled RSS >= 1 GiB,
checked every 50 ms; this is sampled subprocess engineering containment, not a
native hard memory cap. Receipts retain actual elapsed/RSS and child status.
Imports can initialize third-party library internal objects, but no scientific
arrays/inputs/models, numerical outputs, claims or experiment runs are created.
The source-hash mutation is an altered expected hash, not an on-disk source edit.

This does not prove full graph capacity, timing, an empirical fit, numerical
agreement, or identify the exact historical pilot13 changed entry. Independent
review and genuine future registration/admission remain required.
