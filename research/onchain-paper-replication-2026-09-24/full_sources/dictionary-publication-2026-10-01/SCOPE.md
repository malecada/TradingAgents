# Registered first-owner dictionary publication

This isolated component derives the accepted proof-enforcing dictionary driver.
The single change to its result is an internal admitted sample receipt retained
for publication leases. This avoids loading the full sample collection twice.
All pair purposes, matching/clustering settings and scientific choices retain
the accepted driver/workload semantics. Existing accepted sources are unchanged.

The publisher requires actual first-owner admission and an explicit output policy
named identically by the selected job and producer. Source bytes are checked at
the import and admitted roots. The fixed dictionary attempt directory reserves
an exclusive identity before fitting. Every existing partial, failed or completed
attempt refuses a relaunch. Start metadata records the owner, source/policy and
sampler proof. Errors preserve existing files and attempt a failed marker; a
failure after complete publication preserves conflicting markers for later
admission to reject. Exact historical continuation is not implemented here.

The logical output reservation is four metadata allowances plus the component
allowance: start, complete, failed, separate FeatureJournal event and dictionary
component. It excludes pre-existing sample/owner/pair artifacts, which retain
their separate budgets. The registered sample-reader numeric allowance plus
8*max_entries bounds the sample/cumulative dictionary-matrix numeric subset
before fitting. Actual retained sample and matrix nbytes are checked afterward.
Representative arrays alias immutable admitted sample graphs and are not copied
by numeric payload construction. This does not bound parent graphs, pair
workspaces, NumPy/SciPy scratch, Python objects, process RSS or physical blocks.
Those still require independent resource guards/accounting and measured pilots.

The dictionary_complete event includes exact admitted sample/proof provenance,
owner, dictionary identity, derived workload and registered output policy. Numeric
representatives remain native arrays; memberships, hierarchy, training hashes,
configuration and sample identity are preserved. NPY/manifest and actual lifecycle
event encoding are preflighted before FeatureJournal writes. The completion proof
binds exact event/component hashes and reports encoded/numeric sizes. This stage
publishes a first attempt only. A future independent dictionary admission route
must validate proof disposition, artifacts and semantic membership before use.
Completed dictionary reuse without workload/Serial/PairSession APIs, historical
ancestry, mapped full-fold/MCM integration and empirical release remain pending.
