# Non-tail local transport-context preparation

Implemented one new source module, `non_tail_context.py`, in this preparation directory only. Existing transport, tail, reader, Owner and numerical sources remain unchanged. This is a concrete lowest-layer adapter, not an activated transport Context. The candidate loads the exact accepted reader02 and owned_io bytes from their preserved directory with SHA/origin checks; no copied numerical module or empirical data is imported.

## Behavior and concrete authority boundary

`open_context` constructs an actual accepted LocalContent using its real format/header/hash/full-membership/inode validation. `Context` refuses a dictionary or callback instead of that actual class. It derives all names, extents, metadata bytes, hashes and NPY declarations internally. Original score-batch start/header/terminal scope+owner, raw-output owner/stage/contract metadata, and component context/tree/array membership remain exact original bytes. They are content ancestry evidence, not a live Owner capability; the description explicitly says so. All metadata and companion edge-array members are included in full recovery, not only the selected MCM payload. No scalar decoding, numerical values, labels or array module are used.

The member stream is complete original sorted membership with exact contiguous parts. Reservations are shared by an actual immutable `Reservations` instance across successive containers, never reset implicitly between them. Each original/recovered part reserves one proposed command/part and rounds payload bytes up to32KiB, consistent with archive_transport.BLOCK_BYTES. Bytes/commands/parts are cumulative with no refund on failure. A monotonic deadline covers this local context lifetime; it is sampled between checks/reads and is not a hard whole-invocation wall or kernel memory limit. The policy has finite integer caps (including no bool), part<=1MiB, parts<=65,536, commands<=131,072, payload<=1TiB and deadline<=1800s. Full metadata is bounded before capture to4MiB; complete container membership<=4096; per-member ranges are lazy and bounded. These are stricter local engineering preparation limits, not newly admitted production capacity.

`verify_recovery` requires the entire original stream first, a distinct retained local recovery root, exact complete metadata/member names/hashes/length/header semantics, and full recovered body SHA checks. It performs original identity/content checks before and after every part and after recovery closes. The result is explicitly an **unadmitted complete local copy observation**, remote_verified=False, recovery_authority=False, local_bytes_retired=0. Recovery is one-shot in the context. Mutation/refusal revokes the local context and shared reservations. Success closes the local reader but preserves shared cumulative counters for a subsequent container. No file is deleted or overwritten.

First actual fatal identity is preserved across independently attempted close/revocation. Synthetic cleanup uncertainty is distinguished using the actual imported owned_io.CleanupFailure class; no type-name or arbitrary marker substitution. Nonessential exception annotations/cause construction are omitted. An ordinary cleanup error becomes terminal uncertainty. Real reader closure executes once; original evidence is retained.

**Positive transfer activation deliberately refuses.** Main archive_dispatch.binding requires event-specific Ledger/Operation, held token and context population; its preflight uses event budgets. Accepted tail adapter independently refuses because tail population is absent. Neither event operation nor tail local source authorizes f64/f32/NPY members. `activate_transport` cannot turn local metadata, a callback, or caller boolean into such authority. The next Root-owned change must add genuine registered non-tail source membership to original durable Context preflight/capability/operation ledger, bind actual Target/Owner/Stage/held token or admitted cold authority, join source/runtime/job/plan and persist cumulative reservations/revocation/terminal evidence. Command diagnostics, mkdir/control commands, remote names, connection authority and elapsed native transfer policy are NOT supplied by this local counter. It cannot be directly substituted for live archive_dispatch._Budget.
