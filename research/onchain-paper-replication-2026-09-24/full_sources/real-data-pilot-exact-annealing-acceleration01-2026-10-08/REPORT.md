# Bounded exact annealing candidate

Uninstalled candidate only. Main, registrations, native jobs, graph arrays and empirical identities were not changed. Baseline bytes match current Main at manifest generation. Candidate/inverse patches and SHA256 identities are in MANIFEST.json.

Only the edge phase in the actual `_advance_checked` body changes. Chunks contain at most 1024 successive original edge products, bounded additionally by the remaining operation budget. Agreement remains the original scalar `agreement` using Python float subtraction, squared differences, `math.fsum` and `math.exp`. The Python `.5 * agreement` is rounded first; a separate float64 multiplication applies M. `np.add.at` accumulates successive updates, including repeated destinations, in the original order. No reduction, grouping, cached full edge-product table or alternate exponential is introduced. Node, normalization, beta, outer-loop and checkpoint code are byte-identical. State/META/schema and operation accounting are unchanged.

Chunks under eight products, non-float64 edge features and NumPy raise error modes use the original scalar branch. Agreement exceptions replay the successfully computed prefix before raising, preserving cursor/Q/safe state. Ordinary operation boundaries are bitwise verified; asynchronous interruption inside a chunk is not a safe checkpoint and remains excluded. Warning-to-exception policies outside NumPy's error modes are not covered; integration must keep the tested standard warning policy or extend the scalar fallback before using such policies.

Scratch is bounded independently of graph size. Positions, quotient/remainder, weights, two endpoint gathers, and M gathers use at most approximately 112 KiB of simultaneous explicit numeric payload including overwritten local references. Reserve **256 KiB incremental scratch per exclusive call** for this implementation, in addition to existing state, validation/normalization, Python and library overhead. This reservation must be declared before empirical entry and is not a measured RSS or population-capacity guarantee. No resource cap was changed.

TEST01 passed 24,467 bitwise state-boundary checks across asymmetric, tied, empty-edge, repeated-destination, float32 fallback and 1024-boundary fixtures. Budgets included 1; 7/8/9/15/16/17; 1023/1024/1025; and 100000. V/M/Q bytes, every metadata value, phase/cursor and consumed operations agree. Checkpoints produced by the candidate load through the baseline and resume identically. Final hard/soft assignment, score, convergence and iteration count agree. An agreement-overflow fixture also preserves the original failed state and exception class.

TEST02 passed 70 further independent-budget boundary comparisons, baseline-to-candidate checkpoint load, raise-mode fallback, and eight whole-result comparisons against scalar `match_reference`. Tests used pinned Python 3.13.13, NumPy 2.3.0, one BLAS/OpenMP thread, a 512 MiB address-space limit and finite 60-second command guards. No failed test was discarded; both test attempts passed. Checkpoint directories are synthetic evidence; scripts intentionally refuse overwriting them on rerun.

Five tiny synthetic edge-only timing samples had medians 0.03255 seconds baseline and 0.01749 seconds candidate, approximately **1.86x** faster. Agreement evaluation remains scalar. These short samples do not prove complete matching, population throughput, admission, economic validity or real-data speedup. Independent review and root-owned integration remain required. No empirical entry or release follows from this package.
