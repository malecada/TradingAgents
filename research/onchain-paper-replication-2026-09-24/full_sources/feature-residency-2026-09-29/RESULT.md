# Fixed-feature residency increment

Completed fixed graph features can remain on disk until a chronological training
batch needs them. An explicit admitted loading policy bounds unique stored array
bytes before allocation. Verified descriptors preserve original numerical hashes,
including scalar and Fortran layouts. Duplicate graph references share one loaded
object within a batch, and training releases prior inputs before loading the next.

Registered production can publish a graph and release its feature tensor. Journal
verification and failed-parent continuation retain their hash, context, membership
and ancestry checks. Completed registered reuse avoids refitting. The existing
scientific descriptor, dictionary identity and default eager path are unchanged;
no empirical configuration has enabled the new policy yet.
