# Graph representation binding refinement

The pure producer implements the frozen motif dictionary, full-node MCM and
trainable graph inputs, plus declared graph comparators. No empirical features
are produced or admitted by these synthetic checks. The512production sample
count and32motifs remain unchanged; the32-sample fixture exercises interfaces.

The static Node2Vec/WatchYourStep alignment order is increasing graph available_at,
then start_utc, then graph hash. It starts at the earliest event week referenced
by the fixed example population. This refines the declared immediately preceding
available snapshot rule where event and publication order differ. Under the
frozen complete-week+one-day convention they coincide. A delayed earlier week
cannot influence a prediction made before its publication. First orientation is
fixed by seed; each successor is aligned to the immediately preceding available
basis using only common addresses. No common anchors remains unavailable.

Binding schema2 retains every intermediate graph in the alignment dependency
closure, ordered parent links, raw hashes, source hashes, topology/node-order
hashes and clocks. Dictionary training-graph lineage is retained even for
unscored training graphs. Required feature tensors remain restricted to the
fixed example population. The whole binding enters representation identity;
trainable GAT/GIN weights stay in the temporal model.
