# Admitted dictionary pair-consumer construction

This isolated constructor takes an actual OwnedJournal and SampleManifest. The
accepted workload route derives the exact scope from admitted settings and actual
induced sample neighborhoods. Serial receives its matching configuration, logical
pair policy, numerical context, operation slice and publication limit exclusively
from that route. The constructor exposes no caller-selected schedule or scope.

The constructor and its imported Serial/extent sources must be registered and
byte-identical at both the import checkout and admitted run root. A full owner
check precedes construction. Every consumer lease rechecks the actual pair owner,
registered workload/control and those direct source bytes, followed by a fresh
workload lease. A matching numerical result alone does not bypass admission.

Five synthetic tests were first observed failing for missing implementation.
check01 closed with four passes and one test-only failure in 28.843 seconds.
The scalar score agreed, but the test incorrectly expected one reservation per
pair: this pair correctly used two checkpoint publications. Original test and
failure remain preserved. The correction requires a positive reservation count
within the admitted publication cap and no count change on completed replay.
Corrected check02 passed all five cases in 28.747 seconds, exit0. The
implementation source is unchanged; final acceptance is in REVIEW.md. The tests use an actual temporary Git registration,
ResearchRun, FeatureJournal, OwnedJournal and a real synthetic neighborhood draw.
One actual dictionary-workload purpose is captured before pair execution, then
passed to the admitted consumer, compared with the independent scalar reference
and replayed with PairSession.create/resume forbidden. Other cases check altered
samples, changed registered control after construction, unregistered constructor
and a plain object attempting to supply ownership.

## Limits

- Kernel guard observations are mocked. No real empirical resource guard is
  established by these tests.
- The actual synthetic sample draw is not a published/admitted sampler artifact.
  Its publication provenance and exact failed-owner references remain required.
- A consumer's scope and typed graph checks do not independently prove each
  purpose occurs in the dictionary algorithm. Only the actual outer workload
  driver may derive and submit purposes; that complete integration remains due.
- No dictionary/MCM artifact publication, full workload, completed representation
  reuse or mapped full-fold execution is implemented here. The single pair is
  not a feasibility measurement for the dictionary or MCM population.
- Numerical arrays use the existing validated PairSession/extent contract;
  physical whole-workflow quota and orphan reconciliation remain outstanding.
- Independent source and replay checks remain expensive. No scaled runtime claim.
- No maintained package source, scientific protocol, empirical budget or prior
  evidence is changed. All1420financial fits remain pending.
