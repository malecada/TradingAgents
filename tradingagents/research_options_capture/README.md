# Prospective options engineering components

These modules are reviewed prototypes, not a deployable collector or an admitted
experiment. There is no actual prospective grant, claim, source window, worker
assignment or collection process.

- `journal.py`: immutable source-intent, prefix, receipt and recovery storage.
- `transport.py`: public HTTPS attempts only for an already authorized, active
  journal group. It neither creates that authority nor supplies a calendar.
- `control.py`: local phase-control prototype. Its internal verification and
  hash-bound stop declarations do not replace independent source/worker evidence.

The outstanding integration, resource, grant and deployment requirements are in
[the current checkpoint](../../research/strategy-search-2026-09-11/options-capture-engineering-checkpoint.md)
and its linked program state/reviews. In particular, whole-output/staging caps,
independent new-protocol verification, source semantics and enforced remote lease
ownership remain prerequisites. No module here supplies a standalone launch route.

The latest user instruction is to finish the current options/VPS work and then
pause. Do not use this package as authorization for another experiment or wakeup.
